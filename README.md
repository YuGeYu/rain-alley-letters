# 雨巷来信

项目源码与问题反馈：[YuGeYu/rain-alley-letters](https://github.com/YuGeYu/rain-alley-letters)。

雨巷来信是一款 Windows 桌面工具集合。主页提供工具信封目录，顶栏提供主页、收藏、个人和可添加/关闭的网页页签；每个网页使用独立会话，下载保存到首次启动选择的本机文件夹。

## 当前能力

- **浏览器式工具导航**：顶栏固定页签和网页标签并列，网页标签可拖动排序；标签过多时横向滚动，顶栏留白可拖动窗口；下方地址工具栏承载导航、网页收藏、网盘助手、下载管理和设置。
- **信封交互**：主页以信封展示工具；点击和收藏时播放信封翻盖、信纸抽出与封蜡脱落动画，并遵循系统减少动态效果偏好。
- **明暗主题**：默认墨黑模式；可切换以明亮白为主体的亮色模式。主题和功能偏好写入 Electron 用户数据目录，不使用浏览器 `localStorage`。
- **信封收藏目录**：我的收藏、浏览历史、全部工具和网页收藏使用统一的信封卡片；首批显示 6 项，向下滚动或点继续显示后追加内容。
- **账号与评论**：Cloudflare Worker 提供注册、登录、会话和评论接口；随机账号密码会生成 PNG 并保存到本机图片目录，令牌由 Electron `safeStorage` 保护。
- **应用内站点**：网页页签使用隔离的 `WebContentsView`，支持独立导航历史、切换和关闭；默认使用许可 HTTPS 主机列表，其他站点和 HTTP 可通过设置中的相应确认规则访问。
- **网页下载**：首次启动必须选择可写下载文件夹，之后可修改；顶栏可查看下载记录，并暂停、继续、取消任务或打开已完成文件。
- **CS2 人机增强**：提供夸克分享页和 LinkSwift 网盘地址识别入口；自动查找 Steam 库中的 CS2，安装前提示目录结构异常并允许玩家继续。安装前校验官方 v1.4.7 ZIP，备份同名文件后原样复制官方文件，并提供 Panel 启动入口；ZIP 不随应用分发。
- **网盘工具**：可识别八类网盘的公开直链；需要分享页登录态、提取码或动态页面时，在隔离的应用内页面中使用 LinkSwift 助手。
- **低资源运行**：渲染器没有 Three.js、WebGL、Canvas 场景或持续 `requestAnimationFrame`；主进程关闭 Electron 硬件合成，减少 GPU 进程和缓存占用；只在用户主动预览未上架功能时运行短计时器。

网盘地址工具、网页页签、下载管理和 CS2 Bot Improver 安装流程已实现。纯净 B 站视频和猫猫虫表情包仍显示“尚未上架”。CS2 插件仅面向玩家自行启动的本机服务器；分享包只有与经过验证的官方 ZIP 哈希一致时才可安装。

## CS2 饰品工坊与外部应用跳转

附带 Inventory Simulator 3.7.2 原版 ZIP 与中文语言文件，提供清理/备份确认、一键安装、卸载、Steam 本机启动、饰品网站与配置入口。可单独使用，也可与人机增强共同使用；共享运行库按需从经过校验的官方人机增强包提取。

设置中的“允许任意外部应用协议”默认关闭；开启后可确认打开 ccswitch 等应用链接。弹窗显示时原生网页持续隐藏，避免滚动后遮挡确认按钮。

## 运行

环境：Windows 10/11 x64、Node.js 20 或更高版本、npm。

```powershell
npm ci
npm start
```

账号服务不可达时，登录页会保留在本地并给出可重试的错误。站点导航、评论和账号请求均有超时与域名校验。

## 测试与打包

```powershell
npm test
node tools/_ui-runtime-check.cjs
npm run dist
```

安装程序生成到 `release/雨巷来信-Setup-1.0.0.exe`；解包目录为 `release/win-unpacked/`。构建不会把 Cloudflare 管理凭据、账号密码或会话令牌写入包内。

`tools/renderer-smoke.cjs` 检查静态入口、主题令牌、唯一 ID、分页目录、无障碍标签和无旧 3D 文件；`tools/_ui-runtime-check.cjs` 在隔离 Electron 用户目录中检查启动、暗亮主题、主页/目录/详情导航、开信反馈、标签创建/切换/关闭、页签过多时缩短与滚动、下载目录偏好及窗口状态。

## 主要结构

- `src/main.cjs`：Electron 主进程、窗口、托盘、Cloudflare 请求、凭证 PNG 和应用内网页视图。
- `src/preload.cjs`：最小权限 IPC 接口。
- `src/index.html`、`src/styles.css`：登录、工具集合主页、浏览器标签、网页工具栏和高密度中文 UI。
- `src/catalog.js`：功能目录、浏览器页签、认证、主题、安装预览、评论和站点状态。
- `src/features.js`：功能数据、分类、站点地址和上架状态。
- `设计规范.md`：当前颜色、字体、布局、交互、性能与验收标准。
- `功能模块规范.md`：模块注册、真实安装状态、网站与插件边界。
- `cloudflare/auth-api/`：账号、会话和评论 Worker 与 D1 migration。

## 验证边界

已完成 JavaScript 语法检查、静态渲染烟测、Electron 窗口级运行检查和 Windows 安装器构建。自动化环境未通过真实网站完成用户账号访问、网盘授权或文件下载；目标设备安装、显示器缩放、触摸交互及任何游戏内插件行为也未被本轮检查。

卸载与库存共存功能已通过独立文件测试和隔离 Electron 操作验证；未验证玩家真实 CS2 对局。2026-11-01 已获用户确认，进入安装程序构建与交付阶段。

## 卸载人机增强

在 CS2 人机增强详情中选择游戏目录，点击「卸载插件…」。可选择保留人机配置和共享运行库，扫描后确认范围。卸载无需官方 ZIP，也不访问 GitHub。所有移除文件移入游戏目录下的 `.rain-alley-uninstall-*` 恢复备份；未知文件保留，链接与目录联接拒绝处理。程序只移除相关加载入口，不会恢复安装前被覆盖的 Steam 原文件；恢复原版请在 Steam 中验证游戏文件完整性。
