# CS2 卸载与开源准备记录

日期：2026-11-01（北京时间）。本轮完成开发机预览，尚未上传 GitHub、部署服务或构建新安装程序。

## 卸载实现

入口位于 CS2 人机增强详情页。玩家依次选择是否保留配置、是否保留共享运行库；扫描后显示文件数量、内容已改变数量、保留数量与目录，最后再次确认。默认保留配置与共享运行库，取消按钮获得初始焦点，支持 Escape 和弹窗内 Tab 焦点循环。

src/cs2-payload-manifest.json 从用户提供且固定 SHA-256 的官方 v1.4.7 ZIP 生成，记录 562 个文件的路径和哈希。卸载不需要 ZIP 或联网。只逐项移动清单文件，不递归删除 addons、cfg 或 overrides；未知文件和生成的配置始终保留。链接与目录联接在每层祖先检查并拒绝。

src/cs2-uninstaller.cjs 在确认后重新扫描和比较指纹，文件变化需重新确认；移除文件保存在游戏目录 .rain-alley-uninstall-*，保留恢复日志。gameinfo.gi 只删除相关加载行，保留当前游戏其他设置；不会复制旧版官方文件覆盖 Steam 更新。写入失败回滚，回滚不完整时保留恢复记录。恢复安装前被覆盖的 Steam 原文件需要 Steam 文件完整性验证。

主进程校验可信 IPC、目录、确认参数，检查 CS2/Panel 是否运行，安装和卸载共用互斥标记。卸载结果保留备份位置并更新界面安装状态。

## 许可审查

已检查本机源码 ZIP 中主项目 LICENSE（AGPL）与 Panel/LICENSE（PolyForm Strict 1.0.0）的差异。Panel 不按本项目 AGPL 授权，官方 EXE、DLL、VPK、ZIP 不进入源码预览。LinkSwift 1.1.3 保留原版权、AGPL 全文和依赖许可；本项目采用 AGPL-3.0-or-later，新增离线许可入口和第三方说明。

tools/prepare-open-source.cjs 使用白名单准备源码、许可、构建脚本、服务端和迁移，排除生产状态、本机凭据、插件包、安装产物、内部报告及本机专用管理脚本。生成 SOURCE_MANIFEST.json 并执行基础敏感串检查。该自动检查不是对所有第三方权利或潜在敏感信息的无条件保证。
