# 工具跳转、任务栏图标与 Demo 管理

- 工具页普通 HTTP/HTTPS 链接此前被主窗口导航保护直接拦截。现由 catalog 的统一点击代理接入 navigateAddress，继续使用站点权限、网页标签页及错误反馈；已有专用点击处理通过 defaultPrevented 避免重复执行。
- Windows 图标：保留 EXE 的多尺寸 ICO，另生成同源 PNG 供 BrowserWindow.setIcon 使用。Shell ICO 使用内容哈希文件名，避免复用旧路径缓存；修复已有且确实指向当前 EXE 的任务栏固定快捷方式，保留其他应用固定项。
- DemoTracer GUI 增加刷新状态、打开安装目录、卸载。未检测到 GUI 时禁用启动和卸载等操作；异步操作设置 aria-busy 并防止重复点击。
- 卸载调用安装目录中的官方 uninstall.exe，经原生确认后启动交互式卸载。NSIS 的 _?= 参数确保等待真实卸载过程；结束后检查主程序是否仍在，取消时保留定位记录。应用本身不递归删除 GUI 目录或回放数据；官方卸载界面中请保留个人数据。
