## 桌面适配

- 桌面 JSON 存储替代浏览器 localStorage，设置和播放状态通过受信任页面的 IPC 保存，重载后可读取；不清理正常用户配置。
- 自带音乐 API 使用 `127.0.0.1` 动态端口，等待实际监听完成后才创建窗口；关闭应用时释放服务。端口必须传字符串 `"0"`，防止上游将数字 0 回落为固定 3000。
- 保留完整搜索、歌单、歌词、本地音乐、均衡器、下载、扫码登录与账号界面；在线曲目及音质、下载能力服从平台权限。
- 上下文隔离开启、渲染器 Node 集成关闭；完整上游 preload 需要非沙箱模式。保留上游本地音频所需配置，限制特权窗口导航，外部 HTTP(S) 链接交系统浏览器。
- 无封面的本地音频显示默认音符图，避免空字符串封面产生破损图片。
- 配置独立数据目录、单实例唤起、窗口与托盘图标、AppUserModelID。API 日志仅记录路由，不输出请求中的账号参数。
- 复用工作区 Electron 45，通过 `tools/build-xcmusic.cjs` 设置运行时路径，完整构建 Windows x64 客户端。

## 安装与修复

- `src/xcmusic-manager.cjs` 复用参数化安装管理器。先校验 ZIP SHA-256、精确路径白名单、全部文件哈希，再切换 staging；拒绝链接目录。
- 修复和卸下完整保留旧程序目录至 `backup-*`，包括未知文件；个人数据目录和用户下载文件不删除。操作互斥并检测确切 EXE 路径，要求先退出托盘，不强杀程序。
- 实际安装暴露 Electron 将子客户端 `resources/app.asar` 当虚拟目录的问题，导致校验与 staging 清理失败。已改用 `original-fs` 处理托管程序的物理文件；读取雨巷自身随包 ZIP 继续使用 Electron 的常规 fs，兼容外层 app.asar。增加暂时占用清理重试。
- 同一修复用于 BiliDesk，两个管理器的 6 项单元检查全部通过。
