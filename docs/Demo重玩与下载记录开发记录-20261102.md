# Demo 重玩与下载记录修复

本次仅本机开发和预览，未构建雨巷安装程序、部署或上传。

## 资源与安装

- 官方 Playback 1.6.6 ZIP 为 2917653 字节，随应用原样附带。GUI 安装包为 13443850 字节，但专有许可禁止再分发，不能因体积小而打包；改为玩家选择官方安装包或主动在线获取。原始包和每个文件的 SHA-256 见 src/demo-payload-manifest.json。
- GUI 为 NSIS 安装程序，实际程序名为 cs2-demotracer-gui.exe。首次校验安装包，复制到独立临时目录再次校验后运行；完成后记住实际 EXE。后续从记录、标准路径和卸载注册表查找，绝不将 setup 作为日常启动目标。原下载目录启动曾遇到 Windows EPERM，受控临时副本安装通过，未修改原文件或其下载标记。
- 实际在开发机安装并启动了 GUI，路径为当前用户 LocalAppData/Programs/DemoTracer/cs2-demotracer-gui.exe；再次启动也使用已安装 EXE。GUI 保留供预览。
- 回放安装先确认清理其他插件，再询问备份；任一取消均不写游戏目录。共用安装事务、并发锁、游戏进程检查、文件校验和失败回滚；路径拒绝链接与目录联接。清理范围沿用 addons 下插件文件，不扫描或删除原始 Demo、回放库和其他游戏资源。

## 三插件共存

- DemoTracer 1.6.6 要求 Metamod 1483/KHook、CSS 1.0.378 与 .NET 10。现有随附共享运行库符合对应要求；Metamod PE 字符串确认 2.0.0-dev+1483 及 KHook。
- DemoTracer 和人机增强的 BotRandomizer 文件重叠。回放存在时使用回放包匹配的 provider/API/Harmony，后装人机增强或饰品工坊不降级这些组件。
- 卸载人机增强时，回放或工坊存在会强制保留共享运行库；回放存在时保留其 BotRandomizer。卸载回放而人机增强存在时保留 BotRandomizer；工坊不受影响。回放卸载保留运行库和 Harmony。
- 卸载只移动清单文件，并保存恢复备份及指纹校验；GUI、Demo、回放库和个人文件不随回放卸载。状态从实际 DLL 检测，保留手动重检入口。

## 下载记录

原生 WebContentsView 覆盖 DOM 弹窗，旧逻辑将视图缩至零而留下空白。现在仅在打开下载记录前由可信 IPC 抓取当前视图快照，在 DOM 内存中显示为静态背景后隐藏原生视图；关闭移除快照并恢复实际网页，不保存截图到用户磁盘。弹窗期间网页画面静止，页面进程仍运行。标签页变化时不应用过时捕获，Esc 关闭弹窗，Tab 焦点限制在弹窗内。
