## 集成与运行条件

- Inventory Simulator 3.7.2 原版资源包 83,592 字节，随应用保存在 assets/plugins/，SHA-256 为 A50F1A8C4157FF7F613AF59F0E6A4268AFE6A1F858431D15A4E6090CDB32125A。保留 MIT 许可，不修改上游 DLL。
- 用户提供的源码显示目标框架为 .NET 10、CounterStrikeSharp.API 1.0.375；现有人机增强包含 .NET 10.0.3 和 API 1.0.378。库存单独安装时，仅提取共享运行库，不安装 BotAI、其他人机插件或 Panel。
- 共享依赖来源包沿用经过 SHA-256 校验的 CS2BotImprover v1.4.7；优先使用玩家选过的 ZIP 或缓存，否则单次从官方来源下载。库存 ZIP 不需要另行下载。
- 新装运行库默认语言 zh-Hans；已有 CounterStrikeSharp 配置不覆盖。库存页面提供饰品网站、配置目录、游戏内启用命令复制与 Steam 本机启动入口。
- 配置为 cfg/rain-alley-inventory.cfg。进入本机地图后执行 exec rain-alley-inventory.cfg，再使用 !ws。离线 inventories.json 放在 game/csgo，按上游格式导出。Steam 启动入口带 -insecure、练习地图与 exec；真实游戏效果尚未验收。

## 共存与事务边界

- 安装前先询问是否清理其他插件；选择否取消。继续后询问是否保留备份；保留、不保留、取消均有独立分支。
- 清理递归检查 addons 内部，覆盖嵌套 CounterStrikeSharp 插件和 Metamod 加载文件。两款内置插件、配置及必要运行库按文件归属保留；不只依赖界面的已安装标志。
- 安装保留当前 gameinfo.gi，向 SearchPaths 增补所需入口。卸载人机时删除其 botprofile 与对应加载入口，库存仍在时强制保留共享运行库。
- 库存卸载仅处理库存清单与可选的工坊配置，保留人机增强、共享运行库、离线库存与自定义文件。卸载前扫描及指纹确认，移除文件保存恢复备份。
- 安装失败回滚；回滚失败保留原文件和事务记录；提交后临时清理失败不撤销成功。拒绝路径中的符号链接和目录联接。CS2 或 Panel 运行时拒绝修改插件。
- 库存 ZIP 在 Electron ASAR 中先复制到临时真实文件再交给 tar.exe，避免打包后的虚拟路径无法解压。

## 网页与外部应用跳转

- 原问题：滚动和 ResizeObserver 重新计算网页边界时，没有检查弹窗，导致原生 WebContentsView 重新覆盖 DOM 弹窗；标题栏仍受遮罩阻挡，网页却可操作。
- 修复：统一计算边界时检查可见 modal；弹窗存在期间网页边界保持为零。观察弹窗隐藏状态及 DOM 变动，关闭后恢复网页。滚轮、resize、异步网页事件走同一判断。
- 设置增加默认关闭的“允许任意外部应用协议”。开启后 ccswitch 等协议仍逐次询问，确认后使用 shell.openExternal，取消恢复原网页。HTTP/HTTPS 仍按网页规则处理，本地文件、脚本、data/blob 等内容地址不作为外部应用协议执行。
- 长导入链接支持到 16,000 字符，不将链接内容存入偏好或开发记录。未注册应用时返回友好错误。
