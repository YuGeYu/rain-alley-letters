# 固定标签与全部标签页浮层

2026-11-05，本机开发与隔离预览完成，未构建安装包、部署或上传。

## 问题与修改

- 标签原来使用弹性宽度，且顶栏悬停、窄窗口样式会覆盖宽度；统一为 136px，不随数量、标题、悬停和窗口宽度伸缩。关闭按钮固定在右侧，保持可见。
- 去掉按标签总数截断标题的逻辑，改由固定空间内的 CSS 省略号显示；完整标题仍可悬停查看。
- 顶栏保留新建按钮，增加始终可见的全部标签页按钮与数量。列表包含主页、收藏、个人，以及全部工具、设置和网页标签。
- 使用原生 dialog 浮层承载纵向滚动列表；支持切换、关闭普通标签、标识当前页、关闭后保留列表滚动和焦点。固定入口不可关闭。
- 支持 Escape 收起、点击遮罩收起、键盘焦点约束与返回入口；顶栏可用鼠标滚轮横向查看。
- 打开网页上的浮层时，先捕获内存背景再将原生 WebContentsView 边界清零，避免网页盖住浮层；收起时删除背景并恢复实时网页。截图不持久化到玩家磁盘。
- 仅切换所选标签时自动滚动定位，网页标题更新不会反复抢占玩家手动滚动位置。
