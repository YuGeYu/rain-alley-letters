## 相应源码

桌面程序源码位于 src/，资源生成及构建脚本位于 tools/，账号服务源码、迁移及构建配置位于 cloudflare/auth-api/。assets/ 为本项目图标与安装器图片，tools/create-assets.cjs 可生成这些资源。npm 依赖由 package-lock.json 固定，前端内置依赖保留原文件与许可。

LinkSwift 1.1.3 的用户脚本保留上游元数据。雨巷来信新增 Electron 隔离会话、受限 GM API、地址识别、百度授权桥接和主题适配；适配代码在本仓库提供。2026-11-01 新增基于官方清单的 CS2 卸载器、备份回滚、确认界面和离线许可说明。其他已有本地改动随此次源码准备保留，不能以这段变更摘要替代实际源码。

Windows 10/11 x64，Node.js 22 或以上（应满足所装 Electron 构建工具的 engines 要求）：

```powershell
npm ci
npm start
npm test
npm run pack
```

`npm run dist` 使用项目已有直接 NSIS 构建脚本，需要本机具备 electron-builder 下载的 NSIS、nsis-resources 和 7zip 缓存。缓存缺失时会明确失败；可先使用 `npx electron-builder --win --x64` 走标准构建并取得工具。构建需要网络和 Windows 工具链。不要将开发机缓存加入源码仓库。

账号服务开发者应使用自己的 Cloudflare 账号、数据库和域名，按 cloudflare/auth-api/README.md 配置；发布 fork 前修改客户端两份 cloudflare-config.json。源码中的公开服务域名不是部署授权，也不包含生产数据库、账号、口令或会话。网络服务的修改版本应按 AGPL 第 13 节为交互用户提供对应源码获取入口。

## 外部资源边界

CS2 人机增强官方 ZIP、Panel、DLL、VPK 不进入仓库。本项目保留独立的安装/卸载管理实现与官方文件哈希索引。Panel 使用 PolyForm Strict；这是受限制的独立许可，不能因主项目采用 AGPL 就宣称 Panel 可以自由商用或再次分发。最终使用者仍应阅读其许可。

Inventory Simulator v3.7.2 采用 MIT，原版资源 ZIP 与许可随应用保存到 assets/plugins/。清单为 src/inventory-payload-manifest.json，源码来源见 THIRD_PARTY_NOTICES.md。源码预览脚本仅对匹配固定 SHA-256 的该 ZIP 放行，其他外部二进制仍被排除。插件依赖从玩家获取的官方人机增强包中只提取共享运行库，库存独立安装不会安装 Panel 或人机插件。

卸载器无需下载官方包。它仅移动官方清单中的目标文件并修改当前 gameinfo.gi 的相关加载行，始终保留不在清单内的文件，拒绝链接/目录联接。默认保留人机配置和共享运行库；其余移除文件写入游戏目录 `.rain-alley-uninstall-*` 恢复备份。它不会自动恢复以前被安装器覆盖的 Steam 原文件，恢复原版时应使用 Steam 文件完整性验证。

## 待发布目录

`npm run prepare:opensource` 在 release/ 下生成新的、带时间戳的源码预览目录。采用明确的文件白名单，排除 node_modules、构建产物、Cloudflare 本机状态、内部交付报告、账号恢复资料与未获准附带的插件资源包；仅放行清单中固定哈希的 MIT 库存插件包。脚本进行基础敏感串/路径检查并生成文件 SHA-256 清单；此检查不能替代人工审阅和上游权利核查。

上传前检查真实 GitHub 登录用户、仓库归属和公开可见性，并由项目所有者确认。当前文档不代表仓库已经上传，也不构成对所有上游权利问题的无条件保证。
