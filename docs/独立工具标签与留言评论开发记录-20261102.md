# 独立工具标签与留言评论

本次仅完成开发机修改和本地预览，未部署账号服务、执行远程数据库迁移、上传 GitHub/R2 或构建安装程序。

## 功能与实现

- 工具拥有独立可关闭标签；重复打开同一工具切换至已有标签，切换保留输入、事件处理和留言草稿。网站工具打开自己的网页标签。
- 非网站工具采用保留 DOM 的页面切换，异步安装回调通过页面内节点引用更新对应工具，避免误写另一个工具页面。
- 评论使用 root_id 与 reply_to_id：回复留言或回复评论均合入原留言下面，平铺展示并引用回复对象。旧留言使用游标分页，同页留言附带完整评论。
- 删除由服务端 SQL 校验权限：任何账号可删除自己内容；主理人和管理员可删除普通玩家内容，不能互删管理身份内容。
- 删除清除正文并保留占位，其他玩家回复继续保留，引用处显示内容已删除。保留发言时间，删除不重置现有一小时等待。
- 管理员记录在 community_moderators 表，只有服务运营者能够授予；注册、登录输入不能授予权限。账号改名同时迁移管理员身份。

## 后续发布依赖

需要用户确认后先应用 cloudflare/auth-api/migrations/0004_comment_threads.sql，再部署对应账号服务，最后构建客户端。现有线上接口尚不提供新回复与删除能力。迁移新增表、列、索引和触发器，不删除已有留言。
管理员授予使用受控数据库操作向 community_moderators 插入已存在账号；本次未给任何线上账号授予权限。

## 修复经验

初次预览没有开放调试页面，是隔离配置未选择下载目录导致启动等待；预览使用 RAIN_ALLEY_TEST_MODE=1 自动准备测试下载目录。异步读取偏好期间初次窗口 show 事件可能重选主页，因此正式显示工具前再次选择对应工具标签。
更换工具页面不能重新生成整个表单，否则会丢失输入和绑定；保留页面节点并为异步回调保存所属节点引用。删除必须保留发言时间，同时引用内容从服务端当前正文生成，避免已删除正文继续出现在引用里。
