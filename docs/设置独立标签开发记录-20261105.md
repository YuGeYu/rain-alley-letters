# 设置独立标签开发记录

日期：2026-11-05。范围：桌面客户端本地修改与隔离预览。

## 交互

- 点击设置按钮或输入 `rainalley://app/settings`，打开一个可关闭、可拖动排序的设置标签；重复打开复用已有标签。
- 设置标签有独立选中状态、页面地址和辅助功能关联。切换主页、个人、工具、网页后返回，保留账号草稿与滚动位置。
- 从设置访问外部网页时创建网页标签，避免把设置标签转为网页标签。
- 关闭设置使用现有相邻标签回退规则；关闭后台设置不改变当前标签。
- 普通偏好继续即时保存在本机；账号资料继续通过原来的确认按钮提交。关闭标签或退出账号会清除该页面的密码草稿。

## 修复

- 原有设置自动保存计时器会因切离设置页面而跳过保存。现在页面切换后仍保存；关闭标签时立即处理尚未触发的保存。
- 主页和个人页面的公开资料刷新会覆盖设置中的展示名称或账号名称草稿。刷新现在保留未提交的输入，且迟到响应不能更新已关闭设置页的表单。
- 设置标题可接受程序焦点，焦点边框仅包围标题；动态标签选中后可正确滚入可见区域。
- 隔离预览进程使用独立进程组和忽略输出管道，避免脚本结束关闭输出管道后预览窗口随之退出。

- `node tools/renderer-smoke.cjs` 与语法检查通过。

- 深色 1440×960、浅色 1000×760 预览截图已人工查看，未见设置内容横向溢出。
