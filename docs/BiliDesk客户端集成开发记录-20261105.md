# BiliDesk 集成状态

## 当前实现

《雨巷来信》的“B 站 · 雨巷观影”入口在应用自身窗口内打开哔哩哔哩网站，网站视图使用独立的浏览器会话，不会跳转到系统浏览器。它提供 B 站网页本身支持的搜索、登录和播放能力。

这不是 BiliDesk 客户端的嵌入式移植。BiliDesk 1.6.2 使用 WPF、.NET 10 和 LibVLC 原生视频控件；当前没有将它的主窗口嵌入 Electron 内容区域，也没有以独立 Windows 窗口作为雨巷功能启动。功能卡与运行验收均按“雨巷内的 B 站网页入口”描述，不将其称为已集成的 BiliDesk 客户端。

此前制作的原生客户端包和本机验收记录仅说明 BiliDesk 上游程序可单独构建运行，不代表满足同窗嵌入要求，也不作为当前功能实现的验收依据。用户明确要求不能出现独立 Windows 客户端窗口；后续如要达到该要求，需要对 WPF 宿主窗口、原生播放器窗口层级、焦点、DPI、尺寸同步及退出生命周期进行完整适配，并在真实雨巷窗口中验证交互和画面后才能宣称完成。目前保持稳定的应用内网站入口。

## 来源、许可与数据边界

- 上游项目：[ABING1111/BiliDesk](https://github.com/ABING1111/BiliDesk)，GPL-3.0，版本 1.6.2；用户提供源码归档 `E:\dow\BiliDesk-1.6.2.zip`。
- 完整上游源码及适配说明保留于 `vendor/BiliDesk`，许可和第三方依赖说明随源码保留。
- 当前网页入口由 B 站网站提供内容、播放器与账号能力；可访问内容、清晰度和账号操作受 B 站策略及用户账号权限限制。
- 不通过雨巷代理 B 站账号操作，不读取或迁移 BiliDesk 本地登录资料。

## 验收边界

`npm run test:bilidesk` 包含原生客户端管理器的本地单元测试，以及 Rain Alley 内 B 站网页视图运行检查。网页运行检查只证明网页视图可以在雨巷窗口中导航和加载，不能证明 BiliDesk 原生客户端已被嵌入，也不等价于真实账号登录、所有播放源可用或用户设备安装验收。

当前尚未完成 WPF/LibVLC 客户端同窗嵌入，也未为该目标构建新的雨巷安装包或执行远程发布、上传与正式设备安装。
