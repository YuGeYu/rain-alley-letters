# 网站上架与视频全屏修复记录

日期：2026-11-01（北京时间），版本保持 1.0.0。

新增或启用猫猫虫表情包、哔哩哔哩、雾港回响、准星之外、无用技能大挑战。B 站入口使用用户指定的个人空间地址，纯净 B 站工具保持独立。为旧配置一次性加入四个新站点域名，黑名单、禁止全部访问与后续手动移除仍有效。

全屏故障来自 BrowserWindow.fullscreenable=false 和站点会话默认拒绝 fullscreen。修复为仅允许当前可见且符合站点规则的网页请求全屏；网页进入 HTML 全屏时铺满原生内容区域，窗口 resize 不再使用普通网页矩形覆盖全屏尺寸。退出、Esc、导航、销毁与关闭时恢复窗口和视图。离开网页时立即发送隐藏 IPC：全屏网页可能遮住渲染器，使 requestAnimationFrame 暂停，不能依赖下一帧退出。

验证：隔离 Electron 配置中验证旧许可列表迁移、普通页面与 iframe 全屏、Esc、重复进入、返回主页。真实 B 站 BV1GJ411x7h7 的播放器全屏按钮和 Esc 恢复通过；release/preview-bilibili-fullscreen.png 是原生网页截图。五个指定网站通过 Electron net.fetch 均返回 HTTP 200。测试不操作点赞或账号登录。

回归脚本原先假定只加载两批目录；新增项目后扩展为先验证滚动追加，再完成剩余批次。

部署范围是桌面客户端，无需更改五个已有网站、账号 Worker 或 R2。实体玩家电脑安装、所有 B 站账号/视频和多显示器仍需用户侧验收。
