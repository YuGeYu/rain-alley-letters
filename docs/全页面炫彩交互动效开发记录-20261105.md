# 全页面炫彩交互动效

日期：2026-11-05。范围：本地客户端修改与隔离预览；未构建安装包、部署或上传。

## 2026-11-05 频率优化

- 用户反馈全屏效果因普通点击而过于频繁。移除普通点击、表单、设置变化、成功提示和内嵌网站操作触发全屏效果的监听及对应 IPC。
- 鼠标附近柔光与粒子反馈已移除。全屏礼炮仅由账户创建、客户端安装成功等真实里程碑触发，并由主进程持久化限为每小时最多一次。
- `src/celebration.js` 冷却从 30 分钟改为 60 分钟；设计规范和运行检查同步更新。

## 2026-11-05 实测复修

- 根因是另一套全屏 Canvas 交互层会跟随全局鼠标移动绘制；每次点击之前的鼠标移动都会唤醒它，和庆祝礼炮的冷却不是同一入口。
- 移除鼠标跟随 Canvas，主按钮和重点标题不再循环播放渐变。普通点击、鼠标移动、网页操作与主题变化均不创建全屏特效。
- 账号创建与成功安装仍可播放礼炮。冷却申请改为主进程串行检查并落盘，渲染页面不再自行判断；应用重启和并发请求共用同一小时配额。
- 更新运行检查：59 分钟内拒绝、满 60 分钟解锁、并发申请仅一个通过，并验证鼠标移动与普通操作不创建全屏层。

## 视觉与交互

- 共享 `src/effects.js` 覆盖登录、主页、收藏、个人、工具详情、网盘、设置与各类浮层。鼠标移动时显示青蓝与粉紫柔光、旋转光环、短暂粒子尾迹。
- 全屏礼炮限于账户创建、客户端安装成功等真实里程碑；普通点击、主要页面与标签切换、收藏、保存、表单提交、网盘操作、下载和确认均不触发。礼炮约 7.8 秒后清理。
- 动效层不接收鼠标事件，不占布局、不移动焦点，也不延迟原有操作。使用原生 popover 顶层，并在对话框展开时移动到当前浮层内，避免被遮挡或夺走对话框焦点。
- 内置网页在隔离 JavaScript 世界加载同一套本地特效代码；鼠标效果可在网页区域显示。网页点击与提交不会触发应用内的全屏效果。
- 账户创建、CS2 安装成功等真实里程碑庆祝保留；全局持久化冷却为每小时一次，跨应用重启有效。

## 性能与兼容

- 单个 Canvas、约 33fps 绘制上限、固定粒子上限；鼠标反馈与操作动画结束后移除画布并停止动画循环。
- 全屏庆祝约 7.8 秒后清理；普通鼠标移动、网页动作与点击不启动渲染循环。
- 尊重系统减少动态效果、强制颜色、应用轻量模式、页面隐藏与应用挂起。轻量模式同步到已打开的内置网页。
- 无新增外部依赖、网络素材和 localStorage。
