# 雨巷来信 · 设计系统主索引

根目录 [`设计规范.md`](../../设计规范.md) 是当前唯一的视觉与交互来源。这里保留实现检索所需的关键令牌，避免旧的营销页示例覆盖桌面客户端规则。

## 方向

- 产品：Windows Electron 高密度实用功能目录。
- 风格：雨夜编辑感、静态矢量主视觉、标准蓝色常规操作与黄色提醒。
- 参考布局：64px 窗口栏 + 32px 地址状态栏 + 54px 商店栏 + 宽幅 Hero + 精选横排 + 46px 状态栏。
- 动效：重点标题、主操作与完成状态采用科幻炫彩渐变；重大成功操作使用低频、限时的全屏背景礼炮。不使用 3D、WebGL 或常驻帧循环。系统减少动态效果、轻量模式和窗口隐藏时停止相应动效。

## 主题令牌

| 令牌 | 暗色 | 亮色 |
| --- | --- | --- |
| `--bg` | `#000000` | `#FFFFFF` |
| `--surface` | `#080808` | `#FFFFFF` |
| `--surface-2` | `#121212` | `#F3F3F3` |
| `--surface-3` | `#1D1D1D` | `#E8E8E8` |
| `--ink` | `#FFFFFF` | `#000000` |
| `--muted` | `#C8C8C8` | `#353535` |
| `--accent` | `#71B7FF` | `#1764C0` |
| `--accent-2` | `#71C2FF` | `#176BB0` |

字体使用 `Segoe UI Variable`、`Noto Sans SC`、`Microsoft YaHei UI` 回退链；正文基准 15px，常规导航、表单和按钮至少 14px，少量辅助元数据可用 12–13px。组件必须有可见焦点、状态文本和无障碍名称。

地址栏使用 `rainalley://app/...` 表达内置页面，外部页面只接受 HTTP/HTTPS；设置页集中管理主题、导航策略、私网/HTTP/弹窗/下载和网页权限。首页信封卡片纵向排列并逐批懒加载；收藏目录保留紧凑的横向信封浏览，标题栏控制按钮之外的空白必须保持可拖动。
