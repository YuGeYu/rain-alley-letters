# 雨巷主页 · 静态主页覆盖

- 主页只使用本地 SVG/CSS 绘制雨夜主视觉，不加载 3D 引擎、WebGL 或 Canvas 场景。
- 布局使用窗口栏、唯一地址状态栏、商店导航、作品卡片网格和状态栏；首页卡片纵向排列、逐批加载，窗口缩放时保持阅读顺序。
- 暗色以纯黑为主，亮色以纯白为主；面板只用中性灰阶，青蓝光线用于交互强调。避免土黄色、暗金色和大面积绿色。
- 精选卡片、分类目录、详情页和站点页通过同一套卡片、按钮、焦点环和返回入口衔接。主标题与卡片文案不得溢出。
- 只有用户主动点击时才运行安装预览计时器；`prefers-reduced-motion` 下将过渡压缩到最短。
- 页面地址、分类筛选和个人资料都可通过顶栏地址重现；设置页编辑站点许可并即时保存，收藏与历史使用横向信封轨道，不能产生意外的纵向滚动条。主要文字保持 14–15px，只有时间和次要元数据可更小。
