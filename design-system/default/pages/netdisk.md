# 网盘直链工具 · 页面覆盖

- 页面承担真实地址识别、来源平台提示、复制结果和进入隔离网盘页面的下一步；不显示伪造进度、下载成功或绕过登录的承诺。
- 输入区使用清晰标签、多行地址框和“识别地址 / 清空”动作；识别中、需要打开分享页、成功和错误都写入同一处状态提示，并保持 `aria-live`。
- 结果卡片显示文件名、完整地址的省略预览与 `title`，每个复制按钮命中区域至少 36px；“复制全部”仅在实际得到地址后可用。
- 视觉沿用纯黑/纯白、中性面板和青蓝强调令牌，正文保持 14–15px；窄窗口改为单列，不产生横向滚动。
- LinkSwift 来源、版本和 AGPL/第三方许可随包保留；后台请求只允许当前网盘的 HTTPS 域名、有限方法、体积和超时。
- 需要登录、提取码、过期分享或真实账户授权时，明确提示用户在隔离网页中继续；不把雨巷账号令牌注入网页。
- 所有按钮有键盘焦点和可读名称；减少动态效果时跳过信封和结果过渡，但保留状态文本。
