# 网页收藏 · 页面覆盖

- 网页收藏是独立的目录模式，沿用功能目录的页眉、搜索、空状态和横向卡片轨道；地址只接受当前实际打开的 HTTP/HTTPS 网页。
- 卡片显示网页标题、主机名/地址和明确的“打开 / 删除”动作；长标题和地址允许省略显示，但通过 `title` 保留完整内容。
- 收藏按钮位于应用内网页工具栏，使用 `aria-pressed`、动态 `aria-label` 和“收藏网页 / 已收藏”文字同步状态；收藏不能扩展站点许可范围。
- 收藏数据写入 Electron 用户数据目录，打开条目更新最近使用时间并按最近使用优先排序；保存失败要通过可见状态说明。
- 使用中性面板、青蓝强调和 14–15px 正文，删除等操作保持至少 38px 命中区域；没有网页收藏时说明下一步，不留空白误导。
- 键盘焦点必须可见，站点仍使用独立网页视图并为底部 46px 状态栏保留安全空间；`prefers-reduced-motion` 下不依赖动画表达收藏成功。
